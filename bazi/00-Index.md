# BaZi & Destiny Matrix — Index

Catatan lengkap semua bacaan BaZi (dan Destiny Matrix) untuk Alim dan pacarnya, dikumpulkan dari sesi bacaan 1–3 November 2026. Semua tanggal pakai **WIB**, dan tahun/bulan BaZi berganti mengikuti bulan solar (tahun baru BaZi sekitar 4 Februari).

> [!warning] Cara membaca semua catatan ini
> BaZi dan Destiny Matrix itu **peta cuaca, bukan takdir**. Dua-duanya kerangka tradisional/esoteris untuk refleksi, bukan sains, bukan nasihat medis/keuangan/hukum. Pakai untuk saling menjaga dan bersiap, **bukan untuk curiga atau melabeli orang**.

## Tools (di repo ini)

```bash
# Pilar BaZi hari ini (WIB) + catatan singkat untuk Alim, pacar, dan kalian
python3 bazi/tools/bazi_pillars.py

# Tanggal tertentu, atau beberapa hari sekaligus (mis. 7 hari mulai 2027-06-10)
python3 bazi/tools/bazi_pillars.py 2027-06-10 7

# Destiny Matrix Alim + pacar + titik utama matriks pasangan
python3 bazi/tools/destiny_matrix.py 1995-12-02 1998-08-24
```

- Pilar hari dihitung dari jangkar 1949-10-01 = 甲子; pilar bulan/tahun dari bujur matahari (立春 ≈ 4 Feb).
- Untuk memilih tanggal spesifik:
  - **Alim:** pilih hari ber-stem 戊/己/庚/辛; hindari hari 酉 (bentrok 卯), 巳 (bentrok 亥), dan hari 癸.
  - **Pacar:** pilih hari ber-stem 丙/丁/甲/乙; hindari hari 申, 酉, 子.
  - **Kalian:** hari 戌 = hari terbaik untuk hubungan (卯戌合 dua-duanya); hari 酉 dan 子 = sensitif.
